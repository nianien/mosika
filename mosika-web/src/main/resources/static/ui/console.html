核心设计

Mosika 的规则模型

01

统一的规则结构

条件判断和执行流程使用同一种树形结构，覆盖与、或、非、限定匹配、串行、并行、分支和有界循环。

02

分层复用与业务扩展

无参规则、带参模板和完整规则流分层复用；Java 与 JavaScript UDF 用于接入业务能力。

研发维护规则与 UDF，产品和运营负责编排。

03

执行路径与结果解释

画布与运行时共用一套规则语义；执行后直接标出实际路径、循环次数，并把结果翻译成业务说明。
