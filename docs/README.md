## 文档边界

- `AGENTS.md` 是仓库协作约束，不属于产品文档，不移动到本目录。
- `mousika-web/src/main/resources/static/ui/*.html` 是 Web 产品页面，不是静态说明页。
- 文档图片统一放在 [`images/`](./images/)；不再放入模块运行时资源目录。
- 当前设计使用稳定文件名，不在文件名中维护 `v1`、`v2`。历史版本和一次性评审结论由 Git 历史保存，避免并行维护多份事实来源。
- 性能实验、临时基线和演示脚本只有在进入持续维护流程后才保留；一次性且已过期的验证材料不作为项目文档长期存放。
