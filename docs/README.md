# Mosika 文档

根目录 [`README.md`](../README.md) 用于项目概览和快速开始；实现设计、编排契约与运维开发说明统一维护在本目录，分为三份。

| 文档 | 内容 | 主要读者 |
| --- | --- | --- |
| [规则模型核心设计](./规则模型核心设计.md) | 围绕 `mosika-core`：设计理念、DSL 语法、节点体系、引擎装配、求值与缓存、UDF 内核能力与内置库、模板参数、执行详情 | 内核开发者、规则平台接入方 |
| [规则编排交互设计](./规则编排交互设计.md) | 围绕 `mosika-ui`：规则定义与编排解耦、递归树统一串/并/分支/循环、UI 单向编译为 DSL、在线测试与执行路径渲染、画布与版本生命周期 | UI/Web 开发者、产品设计者 |
| [运维与开发](./运维与开发.md) | 工程结构、构建测试、服务脚本与运行配置、部署、Java/JavaScript UDF 的定义装配与使用 | 项目开发者、运维人员 |

## 文档边界

- `AGENTS.md` 是仓库协作与设计指南，`CLAUDE.md` 指向它；二者不属于产品文档，不移动到本目录
- `mosika-web/src/main/resources/static/ui/*.html` 是 Web 产品页面，不是静态说明页
- 文档图片统一放在 [`images/`](./images/)，不放入模块运行时资源目录
- 本目录只保留随代码维护的设计与使用说明，描述最终设计而非演进过程
