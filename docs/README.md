## 文档边界

- `AGENTS.md` 是仓库协作约束，不属于产品文档，不移动到本目录。
- `mosika-web/src/main/resources/static/ui/*.html` 是 Web 产品页面，不是静态说明页。
- 文档图片统一放在 [`images/`](./images/)；不再放入模块运行时资源目录。
- 核心设计、编辑器契约和开发手册使用稳定文件名，由 Git 历史保存变更；规划、方案和评审文档使用版本化文件名，新增版本时保留旧版并在新版记录变更摘要。
- 性能实验、临时基线和演示脚本只有在进入持续维护流程后才保留；一次性且已过期的验证材料不作为项目文档长期存放。
